This repository contains programming problems that I have solved using
Python as part of my learning journey. The main goal is to improve my
problem-solving skills, logical thinking, and understanding of Python
programming.

While solving problems, I focus on understanding the problem,
identifying the input and output, developing the logic, writing
pseudocode, implementing the solution, testing it, and analyzing its
time and space complexity.

The repository covers Python fundamentals such as variables, data
types, conditional statements, loops, functions, recursion, `*args`,
`**kwargs`, strings, lists, dictionaries, pattern programming, and
basic algorithms.

I also explore different approaches to the same problem and use
Python's built-in features whenever they can make a solution more
concise, readable, and efficient.

### 🎯 Goal

Build a strong foundation in Python and problem solving, improve
algorithmic thinking, and prepare for **Data Structures & Algorithms
(DSA)**.

> **Understand the logic → Write pseudocode → Implement → Analyze → Improve.**
