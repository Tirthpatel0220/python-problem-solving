This repository contains programming problems that I have solved using Python as part of my learning journey. The main goal is to improve my problem-solving skills, logical thinking, and understanding of Python programming.

While solving each problem, I focus on understanding the problem statement, identifying the required input and output, developing the logic, writing pseudocode, implementing the solution in Python, testing it, and analyzing its time and space complexity.

The repository includes problems based on Python fundamentals such as variables, data types, conditional statements, loops, functions, recursion, `*args`, `**kwargs`, strings, lists, dictionaries, pattern programming, and basic algorithms. More topics and problems will be added as I continue learning.

I also explore different approaches to the same problem and use Python's built-in features whenever they can make a solution more concise, readable, and efficient.

### 🎯 Goal

To build a strong foundation in Python and problem solving, improve algorithmic thinking, and prepare for learning **Data Structures & Algorithms (DSA)**.

> **Understand the logic → Write the pseudocode → Implement the solution → Analyze the complexity → Keep improving.**

🚧 **This repository is continuously updated as I learn and solve new problems.**

**Language:** Python 🐍
